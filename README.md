# Livraria

Sistema de gestão de livraria desenvolvido em Python e MySQL, com uma nova versão em desenvolvimento utilizando TypeScript e tecnologias web.

## Sobre o projeto

O projeto tem como objetivo desenvolver um sistema para gerenciamento de livros, aplicando conceitos de programação, organização de código e integração com banco de dados.

A implementação original foi desenvolvida em Python com MySQL. Atualmente, o projeto está sendo expandido com TypeScript, com foco na construção de uma interface web e na apresentação visual do catálogo de livros.

## Tecnologias

- Python
- MySQL
- TypeScript
- HTML
- CSS
- Git e GitHub

## Estrutura do projeto

- `2807/`: implementação original em Python.
- `typescript/`: desenvolvimento da versão em TypeScript.

## Status do projeto

A versão original em Python e MySQL está funcional. A versão em TypeScript está em desenvolvimento.
